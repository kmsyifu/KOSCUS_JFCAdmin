Add to Order / Update uses the typed price even if Apply was not clicked. Works like the list: price box, unit list, check mark (or Enter) and X. While typing, the new price is shown in the current price's place, labelled "New". The link is now "Edit Price". The check mark closes the box, the Price line shows "New $x / cs" and a message says to click Add to Order / Update to save it.
*<OrderDtl>: Add Item to Order panel: GP % shows as soon as a JFC item is loaded (was always blank until a price was set).
*<OrderDtl>: Adding or deleting an item keeps the qty / prices typed in the list but not saved yet (no more "Changes in qty will be lost" question).
*<OrderDtl>: Edit is only shown for JFC items with a cost, for JFC admins (before: on every row, doing nothing for other items).
*<OrderDtl>: Fixed: the Set Price OK code read a column (lbPrice_OrderByWgt) the price query does not return.
